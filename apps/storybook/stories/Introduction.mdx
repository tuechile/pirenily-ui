# Pirenily UI

Dark, serif, cinematic React components from [pirenily.com](https://pirenily.com).

Use the sidebar:

- **Foundations › Tokens**: every color, type size, space and radius, with its variable name.
- **Foundations › Effects**: each motion and hover effect on its own, named, with the components that use it. Start here if you're not sure which effect is which.
- **Essentials**: general-purpose building blocks in the Pirenily look.
- **Signature**: the detailed, one-of-a-kind pieces that make pirenily.com feel like itself.

Each component has a **Docs** page with every variant, and a **Playground** story. Open it, then change props in the **Controls** panel at the bottom to see exactly what each one does before you use it.

```bash
npx pirenily-ui add card
```
