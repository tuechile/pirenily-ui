# @pirenily-ui/react

Dark, serif, cinematic React components from [pirenily.com](https://pirenily.com). **[See them live →](https://pirenily.com/pirenily-ui/)**

```bash
npm i @pirenily-ui/react @pirenily-ui/tokens
```

```tsx
import "@pirenily-ui/tokens";
import "@pirenily-ui/react/styles.css";
import { Card, CardGrid, ViewToggle } from "@pirenily-ui/react";
```

Load Crimson Text too (e.g. from Google Fonts).

- **Essentials** (`@pirenily-ui/react/essentials`): Button, Tag, Kicker / PageTitle / PageNote, ViewToggle, SideTabs, Accordion, Card / CardGrid, Lightbox / LightboxImage, Masonry, Navbar, Footer / ContactLinks, Callout / Stats, ReadingProgress, Loader.
- **Signature** (`@pirenily-ui/react/signature`): Finder, HoverPreview, FlipCard, CaseStudy (CaseHero, CaseSection, CaseFigure, CaseMedia, CaseRow, CaseBlock, CtaLink, Rollout, CasePager), ScrollMouse, FireCrackle / useFireCrackle / crackle, Shimmer / FeatherImage.

Prefer owning the source? `npx pirenily-ui add card` copies components into your project instead. Docs and source: [github.com/tuechile/pirenily-ui](https://github.com/tuechile/pirenily-ui). MIT.
