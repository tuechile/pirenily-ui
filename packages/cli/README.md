# pirenily-ui

Copy [Pirenily UI](https://pirenily.com/pirenily-ui/) components into your React project, shadcn-style: you get the `.tsx` and `.css` source and own it.

```bash
npx pirenily-ui init                    # pirenily-ui.json + tokens
npx pirenily-ui add card view-toggle    # plus anything they depend on
npx pirenily-ui add --essentials        # or --signature, or --all
npx pirenily-ui list
```

No dependencies; Node 18+. Source: [github.com/tuechile/pirenily-ui](https://github.com/tuechile/pirenily-ui). MIT.
